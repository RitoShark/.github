<details>
<summary><strong>Plugins & infrastructure</strong></summary>

<br/>

**Textures (`.tex`)**
- [RitoTex-Photoshop](https://github.com/RitoShark/RitoTex-Photoshop) - Photoshop addon. Broad version support, has less formats available
- [Paint.NET-Tex-Plugin](https://github.com/RitoShark/Paint.NET-Tex-Plugin) - Paint.NET plugin. High performance, has previews and supports all the current formats
- [Gimp-Tex-Plugin](https://github.com/RitoShark/Gimp-Tex-Plugin) - GIMP plugin. Cross-platform for linux freaks, works faster on Windows though 
- [TexThumbnailProvider](https://github.com/RitoShark/TexThumbnailProvider) - Windows Explorer thumbnails for <code>.tex</code>files

**3D**
- [Aventurine-League-Tools](https://github.com/RitoShark/Aventurine-League-Tools) - 4.0+ Blender addon to natively load League of Legends files and features to make modding easier
- [RitoShark-Maya](https://github.com/RitoShark/RitoShark-Maya) - AutoDesk Maya addon based on LolMaya for loading League of Legends files using the RitoShark rust backend

**Infrastructure**
- [lmdb-hashes](https://github.com/RitoShark/lmdb-hashes) - 1.8M+ hash -> path cache, fast loading, used across all our apps

</details>
